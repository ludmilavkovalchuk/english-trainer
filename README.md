# English Trainer 🐻 — для GitHub Pages

Два урока по пяти вопросам из последних видимых публикаций канала «Учим Английский Word of the Day», октябрь 2026.

## Размещение на GitHub Pages без сервера

1. Создай **публичный** репозиторий, например `english-trainer`, или открой уже созданный.
2. Скачай и **распакуй** ZIP-архив. GitHub не распаковывает ZIP автоматически при загрузке в репозиторий.
3. В репозитории открой **Add file → Upload files** и загрузи **содержимое** папки: `index.html`, `lessons.json`, `app.js`, `style.css`, картинки и прочие файлы. Все лежат на **одном уровне** — это специально сделано для загрузки через браузер даже с телефона. Затем нажми **Commit changes**. Если на телефоне не видна кнопка Add file, выбери браузерное меню **Версия для ПК**.
4. Открой **Settings → Pages → Build and deployment** и выбери `Source: Deploy from a branch`, `Branch: main`, `Folder: /(root)` → **Save**.
5. Через несколько минут сайт появится на `https://ТВОЙ_ЛОГИН.github.io/english-trainer/`. Точный URL будет в Settings → Pages, кнопка **Visit site**.
6. Открой адрес через Chrome (Android) или Safari (iPhone) и добавь на главный экран. Иконка — тот самый белый мишка.

**Важно:** если имя репозитория отличается от `english-trainer`, меняется только часть URL. Переписывать код **не нужно**: пути к JSON, изображениям, service worker и значкам относительные.

## Как поменять словарь

Все 10 слов — в `lessons.json`. У каждого вопроса:
- `word` — английское слово/выражение;
- `options` — четыре варианта ответа;
- `correct` — строка, **в точности** совпадающая с одним из `options`;
- `example`, `translation`, `note` — пример, перевод и пояснение;
- `image` — имя картинки `scene-*.webp`.

На GitHub можно нажать `lessons.json` → значок карандаша **Edit** → **Commit changes**. На сайте слова обновятся после следующей публикации/перезагрузки.

## Тестирование

Проверяй через GitHub Pages. Для локального теста: `python -m http.server 8000`, затем `http://localhost:8000/`.

PWA использует `./` для установки и офлайн-кеша внутри папки репозитория; встроенные CSS-анимации при правильном/неправильном ответе учитывают настройки уменьшения движения. Рекорды сохраняются только на текущем устройстве.
